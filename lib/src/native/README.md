# Native transport

Zig is the sole implementation. `server_native_transport.dart` keeps native
handles and frame ownership behind the Dart API. `zig_transport.dart` manages
API-DL ports, queue draining, response backpressure and shutdown.

`transport.dart`, `transport_config.dart`, and `transport_types.dart` contain the
shared FFI allocation/ownership contract and validation. The configuration is
generated from `zig/include/server_native_abi.h` by `tool/generate_ffi.dart`.
Exported Zig functions are generated by `tool/generate_zig_bindings.py`.

`hook/build.dart` builds only the Zig asset or resolves a verified Zig
prebuilt. Linux x64 and ARM64 are the supported targets. Backend selection
variables from earlier migration builds no longer select a different runtime.

`test/native_transport_contract_test.dart` checks frame copies, deallocation,
configuration validation and shutdown behavior without native allocation.
Runtime fixtures compare native direct/bridge modes with dart:io.
